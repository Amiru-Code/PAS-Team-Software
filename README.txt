--- Welcome to the PAS Research Group's software folder! ---

The way that this folder's organization works is that the graphing tools are in the 
"Graphing" folder, files for plotting should be stored in the "SParam Files" folder, and 
any images saved from plotting should go in the "Images" folder. When you want to plot a 
.csv file(s), pull it out of the "SParam Files" folder and into the "Graphing" folder. 
When you are done graphing, please put the file(s) back into their folder.
